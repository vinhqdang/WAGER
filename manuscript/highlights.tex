\noindent An Exact Decomposition of Paired Score Differences by Relabelling Within Groups

\vspace{1em}

\begin{itemize}
\item Exact identity splits a paired score gain by relabelling cases within groups
\item The remainder is a within-group forecast-outcome covariance, not classical resolution
\item Cluster-robust inference, a CLT, and reduction to a clustered Diebold-Mariano test
\item Only the covariance part of a reported gain survives a shift in label frequencies
\item A released debiasing method's proper-score gain is almost all transported
\end{itemize}
