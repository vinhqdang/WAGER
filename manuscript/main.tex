\section*{Data and code availability}
All code, cached model outputs and scripts needed to reproduce every number, table and
figure in this paper are publicly available at
\url{https://github.com/vinhqdang/WAGER}. The repository contains the estimator, its
unit tests, every experiment driver, and the cached results files that each reported
value is checked against by an included verification script. The two audited scene-graph
checkpoints are the public release of \citet{tang2020unbiased}; Visual Genome
\citep{krishna2017visual} and CIFAR-100 are public benchmarks.
